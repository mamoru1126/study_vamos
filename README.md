# study_vamos

階層型ナビゲーション VLA「VAMOS」（arXiv:2510.20818）を読むための解説資料。

- 解説ページ：[index.html](index.html)
- 論文：https://arxiv.org/abs/2510.20818
- プロジェクトページ：https://vamos-vla.github.io/

## 見方

`index.html` をブラウザで開く。GitHub Pages（master ブランチのルート）を有効にすると、次の URL で見られる。

https://mamoru1126.github.io/study_vamos/

## 中身

- 要点、2 層に分ける理由、1 回の計画の流れ
- 上位層（VLM プランナー）とその学習データ
- 下位層（アフォーダンスモデル）とシミュレーションでの学習
- 実行時のループ、計算機とセンサ
- 実験結果（6 コースの比較、機体間、言語での操作、データの混合、選び直し）
- 失敗例と限界、OmniVLA との比較、再現のためのメモ、用語集
